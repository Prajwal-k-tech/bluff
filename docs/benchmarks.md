# Simulator tournaments and reproducibility

This page documents the repository's offline bot-vs-bot harness. A tournament
run measures behavior in this simulator only. It does not show that a bot is
strong against people, solves the full game, or generalizes to online play.

## Run the harness

Install the repository dependencies, then run a small seeded smoke test:

```bash
python -m pip install -r requirements.txt
python test_bots.py --games 2 --seed 20261005
```

`--games` is the number of games per matchup. Seats alternate within each
matchup. `--seed` initializes the Python and PyTorch random generators used by
the tournament and stochastic bots. For repeatable output, use the same
repository revision, checkpoint, Python/PyTorch versions, and command. A fixed
seed does not make results comparable across code or dependency changes.

To run more games or save a simulator-generated action log:

```bash
python test_bots.py --games 100 --seed 20261005
python test_bots.py --games 100 --seed 20261005 --log /tmp/bluff-tournament.jsonl
```

The log contains synthetic games generated by this harness. It is not a human
play dataset. `nn/benchmark.py` accepts an explicit checkpoint path for a
learned-policy comparison:

```bash
python -m nn.benchmark --checkpoint /path/to/checkpoint.pt --games 100 --seed 20261005
```

The public repository snapshot does not include a released checkpoint or a
human-play corpus. `test_bots.py` may include neural bot wrappers when their
dependencies are available; if a required checkpoint is absent or incompatible,
the wrapper can fall back. A run with that fallback is a harness smoke test,
not a measurement of the learned policy. Check the run output and checkpoint
loading behavior before interpreting a result.

## What to include with a result

A result intended for review should identify:

- the Git commit and exact command;
- Python and PyTorch versions;
- the checkpoint SHA-256, or state that no checkpoint was used;
- games per matchup, seat assignment, and win/loss/draw counts;
- whether the result is a simulator smoke test, a larger simulator study, or
  evidence from human participants.

Do not publish raw human-play records as benchmark artifacts. Human data needs
appropriate consent and privacy review; simulator traces are not a substitute
for that evidence.

The small command above only checks that seeded tournament execution works. It
is not a strength benchmark. Do not cite tournament standings as human
performance, real-world adaptation, or a result from a model whose checkpoint
was not loaded.
